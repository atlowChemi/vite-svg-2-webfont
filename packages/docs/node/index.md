# Node.js

`@atlowchemi/webfont-generator` runs the fonte engine from Node.js, as a native addon with prebuilt binaries, so generation runs at native speed. The [Vite plugin](/vite/) uses it under the hood.

Use it when fonts are generated by your own tooling: a build script, another bundler's plugin, or a release step. If your app uses Vite, the [Vite plugin](/vite/) does this for you. For shell scripts and CI jobs without JavaScript, use the [CLI](/cli/).

## Installation

::: code-group

```sh [npm]
npm install @atlowchemi/webfont-generator
```

```sh [pnpm]
pnpm add @atlowchemi/webfont-generator
```

```sh [yarn]
yarn add @atlowchemi/webfont-generator
```

```sh [bun]
bun add @atlowchemi/webfont-generator
```

:::

### Platform support

On a supported platform, installation uses a prebuilt addon; consumers do not need
Rust or Cargo. Keep optional dependencies enabled so the package manager can install
the platform binary. Building this repository from source has separate Rust prerequisites;
see the [contributor guide](https://github.com/atlowChemi/vite-svg-2-webfont/blob/main/CONTRIBUTING.md).

The package ships prebuilt native binaries for the following platforms:

| OS             | Architecture          | Target triple                   |
| -------------- | --------------------- | ------------------------------- |
| macOS          | x64                   | `x86_64-apple-darwin`           |
| macOS          | arm64 (Apple Silicon) | `aarch64-apple-darwin`          |
| Linux (glibc)  | x64                   | `x86_64-unknown-linux-gnu`      |
| Linux (glibc)  | arm64                 | `aarch64-unknown-linux-gnu`     |
| Linux (glibc)  | armv7                 | `armv7-unknown-linux-gnueabihf` |
| Linux (musl)   | x64                   | `x86_64-unknown-linux-musl`     |
| Linux (musl)   | arm64                 | `aarch64-unknown-linux-musl`    |
| Windows (MSVC) | x64                   | `x86_64-pc-windows-msvc`        |
| Windows (MSVC) | arm64                 | `aarch64-pc-windows-msvc`       |

## Your first font

```ts
import { generateWebfonts } from '@atlowchemi/webfont-generator';

const result = await generateWebfonts({
    files: ['icons/add.svg', 'icons/remove.svg', 'icons/settings.svg'],
    dest: './dist/fonts',
    fontName: 'my-icons',
    types: ['woff2', 'woff'],
});

// Font data is available directly on the result
console.log(result.woff2); // Uint8Array

// Render the stylesheet for the generated fonts
const css = result.generateCss();
```

`generateWebfonts` writes the generated files to `dest` and returns the font bytes, with methods that render the CSS, the HTML preview, and the [TypeScript metadata](/node/api#generatets).
