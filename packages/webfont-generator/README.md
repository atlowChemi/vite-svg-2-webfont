The [fonte](https://fonte.atlow.dev/) engine for Node.js. It generates icon fonts (SVG, TTF, EOT, WOFF, WOFF2) and their CSS, HTML preview, and TypeScript names from SVG files, as a native addon with prebuilt binaries, so generation runs at native speed. The [Vite plugin](https://www.npmjs.com/package/vite-svg-2-webfont) uses it under the hood.

Use it when fonts are generated by your own tooling: a build script, another bundler's plugin, or a release step. In the browser, use [`@atlowchemi/webfont-browser-generator`](https://www.npmjs.com/package/@atlowchemi/webfont-browser-generator) instead.

## Installation

```bash
npm install @atlowchemi/webfont-generator
```

Supported platforms (macOS, Linux with glibc or musl, and Windows, on x64 and arm64, plus armv7 Linux) get a prebuilt addon and don't need Rust. Keep optional dependencies enabled so your package manager installs the matching binary; see [platform support](https://fonte.atlow.dev/node/#platform-support).

## Quick start

```ts
import { generateWebfonts } from '@atlowchemi/webfont-generator';

const result = await generateWebfonts({
    files: ['icons/add.svg', 'icons/remove.svg', 'icons/settings.svg'],
    dest: './dist/fonts',
    fontName: 'my-icons',
    types: ['woff2', 'woff'],
});

// Font data is available directly on the result
console.log(result.woff2); // Uint8Array

// Render the stylesheet for the generated fonts
const css = result.generateCss();
```

`generateWebfonts` writes the generated files to `dest` and returns the font bytes, with methods that render the CSS, the HTML preview, and the TypeScript metadata.

## Coming from `@vusion/webfonts-generator`

This package is a ground-up rewrite of [`@vusion/webfonts-generator`](https://github.com/vusion/webfonts-generator) in Rust. The original package and its authors deserve credit for the API design and template system it builds on. The API is largely compatible, with a few differences:

- The `cssContext` and `htmlContext` callbacks receive only the context object, not `options` and the `handlebars` instance.
- `formatOptions` is strictly typed as `{ svg?, ttf?, woff?, woff2? }`. The `eot` key is no longer accepted, since EOT is derived from the TTF output.
- Generated font binaries may differ at the byte level, because a different encoder is used, but the fonts are equally valid. CSS, HTML, and template output is identical.
- New options add [incremental updates](https://fonte.atlow.dev/guide/features/incremental), a persistent [engine cache](https://fonte.atlow.dev/guide/features/caching), [multi-weight families](https://fonte.atlow.dev/guide/features/variants), [color glyphs](https://fonte.atlow.dev/guide/features/color-glyphs), TypeScript output, and path optimization. See [configuration](https://fonte.atlow.dev/node/configuration).

For the engine itself, or generation from a terminal, see the [`webfont-generator` crate](https://crates.io/crates/webfont-generator).
